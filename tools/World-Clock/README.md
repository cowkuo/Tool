# World Clock — 世界時鐘

## 功能簡介

實時世界時鐘，顯示台灣、東京、首爾、紐約、洛杉磯、巴黎六大城市的當前時間。

**主要功能：**
- 🌍 多地區即時時鐘顯示
- ⏰ 自動秒數更新
- 🎚️ 手動調整台灣基準時間（所有城市同步連動）
- 📱 響應式設計（桌面、平板、手機）

## 使用方法

1. **查看時間** — 開啟頁面即可看到各地當前時間
2. **調整時間** — 點擊右上方 ⚙️ 按鈕打開設定面板
3. **選擇新時間** — 在日期時間選擇器中設定台灣時間
4. **更新或還原** — 點擊「更新時間」或「還原目前時間」

## 顯示城市

| 城市 | 時區 | 時差 |
|------|------|------|
| 台灣 | GMT+8 | +0h |
| 東京 | GMT+9 | +1h |
| 首爾 | GMT+9 | +1h |
| 紐約 | GMT-5 | -13h |
| 洛杉磯 | GMT-8 | -16h |
| 巴黎 | GMT+1 | -7h |

## 技術細節

- **前端** — 純 HTML + JavaScript，無外部依賴
- **更新頻率** — 每秒即時更新
- **時間計算** — 基於瀏覽器系統時間 + 時差換算
