# CPK — Process Capability Analysis Tool

## 功能簡介

製程能力分析計算器，用於評估製程穩定性與規格符合度。

**計算指標：**
- Cp / Cpk（短期能力）
- Pp / Ppk（長期能力）
- Cpm（以 Target 為中心的能力指標）
- 預期不良率（PPM）與實際超規統計

## 使用方法

1. **輸入量測數據** — 逗號、空白或換行分隔
2. **設定規格限** — USL（上限）、LSL（下限），至少填一項
3. **設定子群大小** — 預設為 1（個別值）；>1 時採用分組管制圖
4. **點擊「分析」** — 生成報告與圖表

## 分析結果

### 能力指標表
- 各項 Cp、Cpk、Pp、Ppk、Cpm 數值
- 預期不良率 vs 實際超規統計

### 常態性檢定
- Anderson–Darling 近似演算法
- 判定資料是否符合常態分佈

### 圖表與控制圖
- **分布圖** — 逐筆資料點 + 常態擬合曲線
- **Q-Q 圖** — 常態性視覺診斷
- **六合一能力圖 (Capability Sixpack)**
  - 管制圖（X̄-R 或 I-MR）
  - 製程散佈 vs 規格寬度
  - 最近 25 筆運行圖

## 技術細節

- **前端** — 純 HTML + JavaScript，無外部依賴
- **演算法** — 自建 erf / normalCDF / invNorm，誤差控制在工程應用範圍
- **統計參考** — Minitab / ISO 21747 標準

## 注意事項

常態性檢定採近似演算法，僅供工程參考。正式品質報告建議使用 Minitab / R / Python(scipy) 等統計軟體覆核。
