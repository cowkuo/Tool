# FPY / RTY 計算機

## 工具介紹

**FPY / RTY 計算機**是一個即時計算製程直通率的工具，幫助生產管理人員快速評估製程能力和整條生產線的質量表現。

## 功能說明

### 核心指標

#### **FPY（首次通過率，First Pass Yield）**
- 定義：某工站投入的產品中，**一次通過不返工**的比例
- 公式：`FPY = 一次通過數 ÷ 投入數 × 100%`
- 範圍：0% ～ 100%
- 意義：反映**單一工站**的質量能力

#### **RTY（整線直通率，Rolled Throughput Yield）**
- 定義：一個產品通過整條生產線從投入到出貨，**不經過任何返工**的概率
- 公式：`RTY = FPY₁ × FPY₂ × FPY₃ × ... × FPYₙ`
- 範圍：0% ～ 100%
- 意義：反映**整條生產線**的端到端質量能力

#### **整線不良率**
- 定義：1 - RTY
- 公式：`整線不良率 = 1 − RTY`
- 意義：有多少比例的產品需要返工或報廢

### 關鍵特性

- ✅ **實時計算**：輸入數據立即更新所有指標
- ✅ **多站支持**：可添加任意數量的生產工站
- ✅ **視覺反饋**：RTY 狀態用顏色表示
  - 🟢 綠色（≥95%）：優異
  - 🟡 黃色（≥85%）：需要關注
  - 🔴 紅色（<85%）：需要改善
- ✅ **瓶頸識別**：自動標出最低 FPY 的工站
- ✅ **Excel 匯出**：將分析結果匯出為 Excel 報告

## 使用說明

### 基本操作

1. **新增工站**
   - 點擊「＋ 新增站別」按鈕
   - 輸入工站名稱（如「鍛造」、「機加工」等）

2. **輸入數據**
   - **投入數**：該工站接收的產品數量
   - **一次通過數**：該工站不返工、直接通過的產品數量
   - FPY 將自動計算並顯示

3. **查看結果**
   - **RTY**：整條生產線的直通率
   - **整線不良率**：需要返工或報廢的比例
   - **最低 FPY 站別**：瓶頸工站

4. **匯出報告**
   - 點擊「匯出 Excel」生成帶格式的分析報告
   - 文件名自動包含導出日期

### 資料管理

- **刪除工站**：點擊工站列表中的「✕」按鈕
- **清除全部**：點擊「清除全部」重置所有數據
- **復原**：使用瀏覽器的返回功能

## 重要概念

### FPY vs Cpk

| 指標 | FPY | Cpk |
|------|-----|-----|
| 衡量對象 | 實際投入產品的通過比例 | 製程能力的理論潛力 |
| 計算方式 | 實際計數（返工/合格） | 統計分析（µ, σ） |
| 適用時機 | 已有返工記錄時 | 尋求製程改善潛力時 |
| 返工後產品 | **不計入一次通過數** | 不影響 Cpk 計算 |

### 注意事項

⚠️ **一次通過數定義**
- 只統計**首次合格**的產品數
- 返工後合格的產品**不計入**一次通過數
- 經返工合格後才能進入下一工站

⚠️ **RTY 乘法特性**
- RTY 是各站 FPY 的**乘積**
- 任何工站 FPY 降低，整條線 RTY 會明顯下降
- 因此工站數越多，RTY 越容易下滑

⚠️ **數據驗證**
- 投入數必須大於 0
- 一次通過數不可大於投入數
- 若數據有誤，工具會提示「輸入有誤」

## 應用場景

### 1. 日常監控
定期輸入各工站的日生產數據，追蹤 RTY 趨勢：
- 若 RTY < 95%：需要立即查找原因
- 若某工站 FPY 最低：優先改善該工站

### 2. 改善評估
改善前後對比 RTY 變化：
```
改善前：FPY₁=98% × FPY₂=95% × FPY₃=90% = RTY = 83.8%
改善後：FPY₁=98% × FPY₂=97% × FPY₃=95% = RTY = 90.3%
```

### 3. 目標制定
根據市場需求設定 RTY 目標，反推各工站的 FPY 要求：
```
目標 RTY = 95%
3 個工站：(0.95)^(1/3) ≈ 98.3% ← 每工站目標 FPY
```

## 常見問題

**Q：為什麼 RTY 這麼低？**  
A：RTY 是各工站 FPY 的乘積。如果有 5 個工站，每站 FPY 95%，RTY 只有 77%。工站越多，RTY 下滑越快。

**Q：返工後合格的產品要算在一次通過數裡嗎？**  
A：不要。一次通過數只算首次合格的產品。返工成功的產品已經無法改進 FPY 和 RTY。

**Q：能用這個工具評估製程改善成效嗎？**  
A：可以。改善前後對比 RTY 變化，能直觀看出改善的實際效果。

**Q：整線不良率 = 100% − RTY 嗎？**  
A：是的。整線不良率反映有多少比例的產品需要返工或報廢。
